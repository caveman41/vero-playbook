# VeroCleaning — робоча база проєкту

Усе, що потрібно для роботи над сайтом **verocleaning.ca**: дослідження, правила, шаблони, дані, технічна документація.

**Зручний перегляд:** відкрий `index.html` — там навігація з кнопками «Відкрити» і «Завантажити» для кожного файлу.
**Жива версія:** GitHub Pages цього репозиторію.

---

## Що це за проєкт

Сайт клінінгової компанії в Торонто. Ключова особливість бізнесу — **фіксовані опубліковані ціни** замість «розрахунок за запитом», як у більшості конкурентів. Це головне УТП, і воно визначає майже всі рішення в проєкті: від структури сторінок до того, як пишеться контент.

| Параметр | Значення |
|---|---|
| CMS | WordPress на Hostinger (shared) |
| Тема | Vero Minimal |
| Код | **WPCode-сніпети**, не файли теми |
| Форми | Fluent Forms Pro |
| Географія | Торонто + 19 міст GTA |

---

## Як користуватись цим репозиторієм

Тут немає коду сайту. Тут — **те, на що спираються рішення**: чому сторінки саме такі, які в них ліміти, звідки брати ціни, як не зламати живий сайт.

1. Прочитай цей README до кінця

## Три файли, які треба знати напам'ять

**`docs/content/vero-facts.json`** — єдине джерело цін і фактів. Якщо число на сайті розійшлося з цим файлом, помиляється сайт. Містить повну формулу калькулятора, extras, знижки, 20 районів.

**`docs/strategy/search-demand-analysis.html`** — фундамент. Якщо незрозуміло, чому сторінки саме такі, відповідь там.

**`docs/tech/site-technical-docs.md`** — як влаштований сайт під капотом. Без нього перший же деплой щось зламає.

## 🔴 Жорсткі правила

Кожне порушення має реальні наслідки, не косметичні.

### Контент і SEO

| Правило | Чому |
|---|---|
| Ціни тільки з `vero-facts.json` | Розбіжність між сторінкою й калькулятором = втрата довіри клієнта на першому дзвінку |
| `AggregateRating` і `Review` у schema не вставляти | Реальних верифікованих відгуків немає. Фейкові = ручні санкції Google |
| Текст FAQ у розмітці дослівно збігається з видимим | Інакше порушення правил structured data |
| Один запит — одна сторінка-власник | Дві сторінки під один запит просідають обидві |
| Нова сторінка лише за наявності осі розведення | Scope, аудиторія, метод або ціна. «Стадія воронки» — не вісь |
| Перше речення відповіді FAQ містить число | Головний важіль потрапляння в AI-цитати |

### Технічне

| Правило | Чому |
|---|---|
| Снапшот сніпета перед кожним редагуванням | У WPCode немає історії версій. Відкату не існує |
| CSS сторінки — пріоритет **50**, не 10 | `Vero_Styles` стоїть на 10. Нижчий пріоритет перекриє сторінкові стилі |
| Умова показу головної — **Front Page** | Головна на кореневому URL, «URL contains» не спрацює |
| Власний префікс для JS нового калькулятора | `Vero_Scripts` глобально займає `veroState`, `veroStep`, `veroPickHome`. Скрипт, що вантажиться останнім, перезапише інший |
| **Не вимикати** `Calculator_CSS` (3818) і `Calculator_JS` (3817) | Виглядають мертвими, але тримають правила приховування розмітки Fluent Forms. Вимкнеш — зламається `/book` |
| Зображення через Media Library, не base64 | На макеті головної base64 займав 80% ваги файлу |
| Перевіряти результат вживу після деплою | Gutenberg часто оновлює структуру, але не текст |

## Поточний стан сайту

### Готове
Головна сторінка (макет + структура) · калькулятор `/book` (залито 29.08.2026) · дизайн-система v3.0 · `/deep-cleaning-toronto`

### Відомі проблеми

| Проблема | Деталі |
|---|---|
| Нуль structured data на головній | `application/ld+json` відсутній. Google не показує ціни й FAQ у видачі |
| Нуль Open Graph | Посилання в месенджерах — голий текст без картинки |
| 80% ваги макета — base64 | Зображення вшиті в код, треба виносити в медіатеку |
| Перекіс перелінковки | 28 посилань на `/book` проти 4 на контентні сторінки |
| `/pricing` і `/commercial-cleaning` на Kadence | Не мігровані: 353 і 18 блоків `wp:kadence` |
| Ціни на решті сайту застарілі | Меню й сторінки послуг пишуть Condo Deep $150, актуально $180 |
| `MANIFEST.md` не оновлювався після 29.08 | Не довіряти як опису поточного стану |

### Не зроблено
Сторінки послуг (крім Deep Cleaning) · cost guide · commercial · add-ons · appliance

## ⚠️ Відкриті питання

Факти, які **не можна вигадати** — потрібне підтвердження власника бізнесу:

| Питання | Що блокує |
|---|---|
| Ціна Rug Cleaning | Сторінку `/rug-cleaning-toronto` |
| Hardwood: чистка чи полірування? | Скоуп якоря `#hardwood` |
| Сума страхового покриття | Комерційну сторінку — ключовий trust-сигнал B2B |
| Чи є bonding, окрім insurance | Те саме |
| Порядок знижок: 15% до чи після −$20 | Приклади розрахунку. Різниця $3 |
| Сабміт форми не протестований | Створить запис в Entries — потрібен дозвіл |
| Конфлікт цін у старому мокапі | Переписування старих money-сторінок |
