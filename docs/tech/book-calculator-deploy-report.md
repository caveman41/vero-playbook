## 4. Поведінка

- **6 кроків**: Type · Space · Contact · Extras · Add-ons · Book
- **Confirm тепер справді надсилає заявку.** Стара `vcOnSubmit` била тільки в
  неактивований Stripe-ендпоінт `wp-json/vero/.../create-checkout`; звернень до
  Fluent Forms у коді не було взагалі. Новий `vc2Submit` заповнює дев'ять прихованих
  полів (`total_price`, `clean_summary`, `promo_code`, `booking_date`, `booking_slot`,
  `client_name`, `client_email`, `client_phone`, `client_address`) і тисне рідну кнопку сабміту.
- **Бейсмент** — для House і Townhouse; для Condo прихований і обнуляється.
- Платіжний блок і таймер «слот тримається 10:00» із макета не реалізовані —
  Stripe не активований, таймер це вигаданий дефіцит.
- Рядок «🎁 Loyalty perk» прибраний — неперевірюване твердження.
